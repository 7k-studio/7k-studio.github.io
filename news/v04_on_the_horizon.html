The version 0.4 is on the horizon

28.09.2026 v0.4

Current state of Daedalus

Since the last update there has been a true redesign underneath the Deadalus program. One changed triggered another. What started as just an improvement of the airfoil design process ended up with need to redesign whole wing structure. Redesigning geoemtries caused new challenges to appear. At the same time, it was decided to swith from no longeer supported PyQt5 to PyQt6. This an other [what felt like] small changes caused an avalange almost a year long.

Was it worth waiting?

I can only hope it was. But the new version will bring you new possibilities such as:

  • New and Updated Widgets
  • Module-based Menu Bar
  • Home Screen in place of Spalsh Screen Menu
  • More reliable STEP export
  • Custom color schemes

What comes next?

I'm not announing any release date for the new version yet. The program must undergo testing to verify that changes did not cause decrease in stability.
